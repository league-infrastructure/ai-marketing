# Layout Evaluation Rubrics

## Postcard (4×6)
- [ ] Correct aspect ratio (2:3 portrait or 3:2 landscape) — visually assessable
- [ ] Hero image fills 70-80% of the card
- [ ] Headline text is integrated in style-appropriate treatment
- [ ] League logo is present and unobtrusive
- [ ] Clean margins — no content bleeding to edge unless intentional
- [ ] Print-quality feel at intended resolution
- [ ] Information hierarchy: image → headline → logo

## Business Card
- [ ] Correct aspect ratio (7:4 landscape) — visually assessable
- [ ] Single strong visual element dominates ~65% of card
- [ ] Image works at SMALL scale — details don't get lost
- [ ] Organization name is legible
- [ ] League logo is present but not dominant
- [ ] No cluttered compositions — business cards need breathing room
- [ ] Contact info area is clean and readable (if present)

## Individual Cut Images
- [ ] Subject has clean, fully defined silhouette
- [ ] No background scene elements touching the figure
- [ ] Background is transparent, solid white, or easily removable solid color
- [ ] No shadows extending beyond the subject
- [ ] No connecting lines or elements to off-screen
- [ ] Subject is centered and fills the frame appropriately
- [ ] Works as a standalone asset for compositing

## Individual Panels (Web)
- [ ] Correct panel format (wide hero, square social, tall sidebar, or section divider)
- [ ] Panel border treatment is appropriate to the art style
- [ ] Room for text overlay on the designated side
- [ ] Composition communicates instantly at web viewing size
- [ ] One clear action/emotion/moment — not multiple competing focal points
- [ ] Suitable for the intended web placement (hero, inline, divider, CTA)

## Full-Page Flyer
- [ ] Correct aspect ratio (8.5:11 portrait)
- [ ] Hero image occupies top 40-50% of page
- [ ] Headline is prominent and integrated with art style
- [ ] Body text/information blocks are readable and well-organized
- [ ] Call to action is prominent and clear
- [ ] Logo and branding in footer
- [ ] Information hierarchy: image → headline → details → CTA → logo
- [ ] Not visually overwhelming — designed to be read

## Cross-Cutting Layout Checks (All Formats)
- [ ] Text is legible at intended print/view size
- [ ] Color contrast is sufficient for readability
- [ ] The format's purpose is clear from the composition alone
- [ ] Art style and layout format are harmonious, not fighting each other
