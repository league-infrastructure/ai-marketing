# Evaluation Rubric: 8-Bit Video Game

## STYLE FIDELITY (Weight: 35%)

### 1. Pixel Rendering (Pass/Fail — gate check)
- [ ] Individual pixels are discernible as colored squares
- [ ] No anti-aliasing, smooth edges, or sub-pixel rendering
- **FAIL if:** Image has smooth edges, gradients, or no visible pixel grid

### 2. Color Palette
- [ ] Authentic NES palette limitations: ~4 colors per sprite
- [ ] Total palette drawn from the NES 54-color master palette feel
- [ ] Characteristic bright primaries, bold secondaries
- [ ] Not modern full-color or high-color-count sprites

### 3. Sprite Style
- [ ] Black or dark-colored outlines on sprites
- [ ] Flat pixel colors with dithering patterns where needed
- [ ] Sprites at believable NES scale (16×16 to 32×32 feel)
- [ ] No smooth shading, gradients, or modern pixel art techniques

### 4. Background Rendering
- [ ] Tile-based backgrounds with repeating 16×16 tile patterns
- [ ] Simple parallax layers (if multiple layers)
- [ ] Solid color sky or simple gradient dither
- [ ] Not smooth gradient backgrounds or photorealistic environments

## COMPOSITION (Weight: 30%)

### 5. Game Format Authenticity
- [ ] Matches a recognizable game genre format (side-scroller, title screen, etc.)
- [ ] Appropriate UI elements for the format (HUD, dialog box, etc.)
- [ ] Feels like a direct NES screen capture

### 6. Spatial Organization
- [ ] Characters and objects arranged appropriately for the game format
- [ ] Ground tiles, platforms, and environmental elements make game-design sense
- [ ] Not cluttered — NES games had limited sprite counts

### 7. UI Elements (if applicable)
- [ ] HUD, score, lives, or dialog boxes rendered in 8×8 pixel font
- [ ] Text is all-caps, blocky, characteristic NES font
- [ ] UI elements are correctly positioned (score top-left, lives top-right, etc.)

## TECHNICAL QUALITY (Weight: 20%)

### 8. Authentic Limitations
- [ ] Respects NES hardware limitations: limited sprites per scanline feel
- [ ] No transparency effects, alpha blending, or modern visual effects
- [ ] Color count is believable for 1980s hardware

### 9. Pixel Art Cleanliness
- [ ] No jaggies from poor scaling — nearest-neighbor scaling only
- [ ] Dithering patterns are clean and intentional
- [ ] No mixed resolution (some areas high-res, some pixel)

### 10. Consistency
- [ ] All elements are at the same pixel scale
- [ ] Sprites, backgrounds, and UI share the same resolution feel
- [ ] No SNES 16-bit elements mixed in

## CONTENT ACCURACY (Weight: 15%)

### 11. Subject Correctness
- [ ] Correct subjects rendered as NES sprites
- [ ] Characters recognizable despite pixel abstraction
- [ ] Action/scene matches the description

### 12. NES Charm
- [ ] The image has the characteristic charm and personality of NES-era games
- [ ] Not sterile or overly polished
- [ ] Feels nostalgic and playful, not corporate

## SCORING

- **PASS:** ≥ 9/12 AND pixel rendering gate check passed
- **REVISE:** 6-8/12 or correct pixel style but palette/scale issues
- **FAIL:** < 6/12 or smooth/non-pixel rendering
