# 1940s Comic Book — Negative Prompt

Do NOT include any of the following:

Ben-Day dots or halftone patterns (the #1 difference from pop-art — this style uses flat
color, never dots), cross-hatching, rendered gradients, fine line texture, airbrush,
glossy modern digital coloring, soft shading.

Photorealism, 3D render, CGI, painterly brushwork, Funko Pop influence, vinyl-toy
proportions, chibi, oversized heads, Pixar, anime, cartoon-merchandising look, modern
digital-illustration style.

Cluttered rooms, extra props, or detailed backgrounds — backgrounds are flat color zones
only. Invented posters, signs, slogans, labels, or extra lettering beyond the exact text
specified. Text or code on walls, furniture, robot parts, tools, clothing, or monitor
backs — code appears only on a front-facing laptop screen.

Weapons, lasers, explosions, or military imagery. Photorealistic identifiable faces —
faces must read as illustrated comic characters. Overly detailed or realistic robots —
robots stay low-detail and iconic like the characters.
